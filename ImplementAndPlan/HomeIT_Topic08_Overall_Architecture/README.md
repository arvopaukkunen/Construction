# HomeIT — Overall Architecture (v2025-08-16)

This package contains a **top‑level architecture** that ties together all topics built so far:
- MariaDB (basic & HA Galera), HAProxy, Keepalived
- Home Assistant + Legrand Valena
- Node‑RED (Sabiana, Vallox)
- InfluxDB + Victron MQTT + Telegraf
- iOS app (.NET MAUI, HomeKit)
- Raspberry Pi networking (static IP, Wi‑Fi disabled)
- Dev toolchain (VS Code + Arduino/Opta)

See `docs/overall_architecture.md` and the SVG diagrams in `images/`.
